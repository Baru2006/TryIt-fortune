# 🔮 TryIt Fortune

Telegram Mini App — Fortune Reading with Modern Glass UI.

## ✨ Features

- 12 Zodiac Signs
- 3 Time Periods (Today / Month / Year)
- 10 Questions · 5 Categories (Love, Health, Family, Work, Money)
- Lucky Color · Number · Day · Time
- Adsgram Rewarded Ads
- Fully Responsive
- English + Burmese Mix

## 🚀 Deploy

**GitHub Pages**
1. Upload files → Settings → Pages → main branch

**Vercel**
1. Import repo → Auto-deploy
